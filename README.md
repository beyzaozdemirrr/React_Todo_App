       React To-Do App
Bu proje, React ile geliştirilmiş sade, modern ve kullanıcı dostu bir To-Do (Yapılacaklar) uygulamasıdır.  
Kullanıcıların günlük görevlerini yönetebilmesini kolaylaştırmak için geliştirildi.

---

 Özellikler

-  Görev ekleme  
-  Görev silme  
-  Yapıldı olarak işaretleme (çizgili görünüm)  
-  Görev güncelleme (inline edit)  
-  Yapıldı görevlerde butonlar gizlenir  
-  Cam efekti ve pastel renklerle şık tasarım  
-  Mobil ve masaüstü uyumlu responsive yapı

---

Kullanılan Teknolojiler

- [React](https://react.dev/) (Functional components & Hooks)  
- CSS (Glassmorphism + geçişli renkler)  
- [Vite](https://vitejs.dev/) ile hızlı geliştirme ortamı
